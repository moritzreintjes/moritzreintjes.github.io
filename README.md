# Moritz Reintjes — academic website

Static academic website prepared for GitHub Pages.

## Files

- `index.html` — homepage
- `research.html` — research program
- `publications.html` — complete publication list
- `students.html` — Ph.D. supervision
- `talks.html` — talks
- `teaching.html` — teaching
- `cv.html` — HTML curriculum vitae
- `styles.css` — all visual styling
- `site.js` — very small helper script

There are deliberately **no PDF files or PDF download links** in this version.

## Publish at moritzreintjes.github.io

1. Create (or open) the GitHub repository `moritzreintjes.github.io`.
2. Upload **all files in this folder** to the root of that repository. `index.html` must sit at the root level.
3. Commit the upload.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch `main` and folder `/(root)`, then save.
7. The website will publish at `https://moritzreintjes.github.io`.

## Updating the site

Edit any `.html` file directly on GitHub or upload a replacement file and commit the change. GitHub Pages will republish automatically.
